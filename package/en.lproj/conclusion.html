Please save your current work, then log out and log back in to complete installation of this input method.

After logging back in:

  1. If Squirrel is not in your input source list, add it from System Settings → Keyboard → Text Input → Input Sources.
  2. Voice input requires the Input Monitoring permission: System Settings → Privacy & Security → Input Monitoring, and enable Squirrel (a prompt also appears on first hotkey use).
